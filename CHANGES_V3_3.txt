SKE TRUCK DEV V3.3 — Network Handoff Fix
(แก้ปัญหา: สลับ WiFi/มือถือแล้วขึ้นแดงค้าง ต้องลบข้อมูล Chrome ถึงจะใช้ได้)

สาเหตุที่เจอ:
1. ระบบ auto-recovery ตอนสลับเน็ตเวิร์ก (_runHandoffRecovery) ถูกล็อกไว้ไม่ให้ทำงาน
   ถ้าเซสชันนี้ยังไม่เคยเชื่อมต่อสำเร็จมาก่อนเลยสักครั้ง (_handoffEverConnected)
   -> เอาเงื่อนไขนี้ออก ให้ลอง recovery ได้เสมอเมื่อเน็ตเวิร์กเปลี่ยน
2. ถ้า probe REST ไปยัง Firebase ไม่ผ่าน (แม้ navigator.onLine=true) ระบบจะ "ยอมแพ้" ทันที
   ไม่ลอง reload เลย ทั้งที่ปุ่ม reload คือสิ่งที่ทำให้หายได้จริง (คล้ายกับที่ลบ browsing data ทำ)
   -> เพิ่มการลอง probe ซ้ำ 2-3 รอบ ถ้ายังไม่ผ่านให้ลอง reload อยู่ดี แทนที่จะค้างเฉยๆ
3. Reload cooldown เดิม 2 นาที นานเกินไป ทำให้ผู้ใช้รอไม่ไหวแล้วไปลบข้อมูลเองก่อน
   -> ลดเหลือ 45 วินาที
4. ปุ่มลับ "แตะเวอร์ชัน 5 ครั้ง" (debug log) เดิมใช้ได้เฉพาะตอน login แอดมิน
   -> แก้ให้ใช้ได้จากทุกหน้ารวมถึงหน้าคนขับ เผื่อต้อง debug เพิ่มในอนาคต

ไฟล์ที่แก้: index.html เท่านั้น (sw.js, manifest.json ไม่ได้แตะ)

เวอร์ชันที่ต้องเห็นหลัง deploy: v2026.07.26-dev-v3.3-network-handoff-fix

วิธีทดสอบ:
1. เปิดแอพด้วย WiFi ให้เชื่อมต่อติด (ไม่ขึ้นแดง)
2. ปิด WiFi ให้สลับเป็นเน็ตมือถือ
3. รอดู — ไม่ควรต้องแตะอะไรเลย ควรกลับมาเชื่อมต่อเองภายในไม่กี่สิบวินาที
   (อาจเห็นหน้ารีเฟรชสั้นๆ 1 ครั้ง เป็นเรื่องปกติ คือกำลังสร้าง connection ใหม่)
4. ถ้ายังแดงค้าง ลองแตะปุ่มในแบนเนอร์ ควรลองสร้าง connection ใหม่ให้ทันที
5. ไม่ควรต้องลบข้อมูล Chrome อีกต่อไป — ถ้ายังต้องลบอยู่ ส่ง debug log มาดู
   (แตะข้อความเวอร์ชัน 5 ครั้ง ตอนที่ยังแดงอยู่ แล้วกดคัดลอกทั้งหมด)
